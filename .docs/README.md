# SketchTask Documentation

`.docs` chứa tài liệu sản phẩm, kiến trúc, dữ liệu, phát triển và kiểm thử của app.

- [APP-OVERVIEW.md](./APP-OVERVIEW.md): mục đích và phạm vi app.
- [FEATURES.md](./FEATURES.md): tính năng và trách nhiệm từng khu vực.
- [ARCHITECTURE.md](./ARCHITECTURE.md): cấu trúc client/backend và đồng bộ.
- [DATA-MODEL.md](./DATA-MODEL.md): mô hình dữ liệu và trường thời gian.
- [LOCAL-DEVELOPMENT.md](./LOCAL-DEVELOPMENT.md): chạy app trên localhost.
- [QA-CHECKLIST.md](./QA-CHECKLIST.md): checklist kiểm thử.
- [KNOWN-ISSUES.md](./KNOWN-ISSUES.md): giới hạn và việc còn lại.

Tài liệu UX/UI nằm trong `.design`. Task và báo cáo Antigravity nằm trong `.agents`; log nghiệm thu Codex nằm trong `.agent`.
