# Design System

This directory is the source of truth for the application's visual and UX design.

All frontend agents and developers must consult these documents before creating or modifying UI.

## Design Documents

### 1. DESIGN-PRINCIPLES.md

Defines the visual identity, personality, philosophy, and core design principles of the application.

### 2. TOKENS.md

Defines the reusable design tokens such as colors, typography, spacing, borders, radii, shadows, and other visual values.

## Rules

- Do not invent a new visual style without updating the design system.
- Reuse existing design tokens whenever possible.
- Do not create one-off visual patterns when an existing pattern can be reused.
- Preserve consistency across mobile and desktop.
- UX clarity and usability take priority over decorative elements.
- The design system should evolve deliberately rather than through isolated UI decisions.

## Current Design Direction

Hand-Drawn Productivity / Digital Sketchbook

The interface should feel human, playful, creative, warm, and organized while remaining practical for a productivity application.
